## Pilot replacement verdict

**No replacement.** All three are stronger as beat sheets than as loglines, and each now has a repaired weakness (see "Changes from the v0.2 concept" in each file).

**Watch item: Pilot 2** carries the project's biggest comprehension risk (`RSK-0005`: can a four-year-old read a *hidden* feeling?). It was repaired with look-then-straighten staging, foreground/background composition and one in-character anchor line. If the silent animatic shows 4-year-olds can't follow it, the planned substitute is **Kite Day** from the [shortlist](../PILOT_CANDIDATES_V0.2.md) (Tekla must be fun on command; it also tests wind). Do not swap on desk judgment alone.

## Recommended order

- **Viewing order:** P3 → P1 → P2. P3 teaches the drip code and creates the chimes. P1 teaches Tekla's pride and "I'm fine". P2 is richer once both codes are known.
- **Production and benchmark order:** P1 → P3 → P2. P1 is Tier A and the cheapest benchmark mini-scene (B10). P3 holds the hardest recurring effects (B3, B4). P2 needs the visitor asset.
- **Continuity across that viewing order:** the chimes hang by the door in P1 and P2. The Keep Shelf reads: lace leaf → chair leg → crooked pinecone.
